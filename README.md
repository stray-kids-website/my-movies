🎬 Movies Collection Website

📌 About the Project

The Movies Collection website is a simple and attractive website designed to display a collection of movies. Users can browse movie posters, view movie titles, check release years, and explore different movie genres.

The website uses a dark cinema theme with red highlights to create a movie-streaming-inspired design.

✨ Features

🎥 Display a collection of movies.

🖼️ Show movie posters and images.

📅 Display movie titles and release years.

🎭 Organize movies by genre.

🔍 Search bar design for finding movies.

🎨 Dark theme with red highlights.

📱 Responsive layout for mobile phones and computers.

🖱️ Hover effects on movie cards.
